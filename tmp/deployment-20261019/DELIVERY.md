# 部署代码首步交付（2026-10-19）

本轮完成检测软件的路径、首次参数、串口绑定和首次授权处理。源码已修改，真实解决方案产物隔离于 `build-final`。未覆盖公共 bin，未制作 Setup，未安装软件、替换 GPU 环境或验证 5070/30/40 系。

## 路径与首次安装

- `CommonCls/ApplicationPaths.cs` 统一定位：安装资源基于 `AppDomain.CurrentDomain.BaseDirectory`，机器数据基于 `%ProgramData%\ElectrodeDet`，授权保留 `%APPDATA%\GearDet\authentication.txt`。
- 安装介质后续必须提供 `VPP\LD.vpp` 和 `Assets\Models\Default\inference_model\`。本轮未向隔离构建目录复制实际模型/VPP；仅复制 EXE/DLL 不能作为完整部署。
- 首次启动将安装目录中的 LD.vpp 复制到 `%ProgramData%\ElectrodeDet\Workspaces\Default\VPP\LD.vpp`，供现有 VPP 编辑/保存功能使用。工作区已存在 LD 时不覆盖，不引入 Measure 或其他旧 VPP。安装资源缺失时不伪造成功。
- 参数存于 `%ProgramData%\ElectrodeDet\UserData\serUserParam.json`；普通图像、日志、场景、标注、记录清单等写入机器数据目录。原图保存路径仍可由用户设置完整绝对路径。
- 运行时路径规范为完整路径；安装目录内的模型路径保存为相对安装目录的路径，重读后恢复完整路径。普通相对数据路径按数据根目录解析，VPP 相对路径按工作区解析，不替换盘符猜测文件。
- 新机不自动读取、复制或迁移程序目录/工作目录中的旧 JSON、DAT、历史运行统计、旧授权种子。原设备旧配置仍在原位置；首次运行本版会使用独立的新配置，设备须重新分配。已有机器数据目录内的有效参数继续读取。
- 新参数保持 GPU=true/GPU0、视觉模式和现有算法阈值默认值；默认相机索引 -1、序列号为空、工位与串口均未启用，自动连接/自动运行关闭，IO反馈关闭。设备参数由用户在现有参数窗口设置。
- JSON 保存使用临时文件+原子替换，保留 `.bak`。读取损坏配置会报告完整错误并保留原文件，主界面自动保存被阻止；用户明确确认参数后才允许替换。
- 后续安装器负责为运行账户配置机器数据目录的写入权限；本轮未验证 Program Files 安装和普通账户 ACL。

## 串口

- 保留四个逻辑槽和 `serInd` 兼容字段，新增 `portNames`/`deviceIds`；打开与重连不再使用 `serInd`。
- 参数窗口显示 COM 号及取得的设备名称。能读取 PNPDeviceID 时按身份恢复当前端口；否则保存用户明确选择的 COM 名称，不按列表位置恢复。
- 原设备缺失、身份查询失败或匹配不唯一时保持未连接；有身份绑定时不退回同名 COM 猜测。多个已启用槽重复绑定同一端口时拒绝打开或保存。
- 只有旧序号的配置需要人工重新分配；UI 不自动选中第一个端口。未启用的槽允许未分配，不要求为了保存其他参数插齐全部串口。
- 参数确认后若串口设置改变，释放旧连接；手动连接或已启用的自动连接采用新绑定。参数刷新只更新 UI，不发送亮度或控制指令。
- PNPDeviceID 不等于所有适配器都具有跨插孔不变的唯一序列号。无唯一身份的设备、换适配器/插孔导致身份变化时需要重新分配；未实现遍历端口发送动作来识别设备。
- 第4槽仍为外部 IO，仅启用且 OS 打开后注册接收；0x45 报文、偏移、CRC、A/B输入映射和输出协议未修改。绿色连接状态不能代表业务触发或物理输出已验证。

## 授权与首次密码

- 首次创建未绑定、已过期、无预设登录密码的授权文件，不再复制程序旁 `authentication.txt`。已有用户授权文件保留。
- 保留既有机器码/注册码编码格式及 MAC+期限验证。优先保留已授权网卡，首次选择以太网并支持无线网卡回退；空、未知和全零 MAC 不接受。
- 拒绝其他机器、过期、格式错误的注册码；保存失败返回失败并恢复内存状态，不显示虚假注册成功。日期新写入采用区域无关格式，保留旧日期读取兼容。
- 新机流程：获取机器码 → 正常申请并输入本机注册码 → 设置操作员/管理员/主管密码 → 重启 → 登录后设置相机、串口和现场路径。复用现有密码窗口，无默认通用密码；修正操作员初值误读管理员密码的问题。
- 授权校验或持久化失败阻止本轮初始化并报告错误。密码设置取消时不继续首次初始化。现有有效且已有密码的授权不要求重新设置。
- 此项是部署流程补齐，不是更换授权算法或完成安全审计；不代替 VisionPro/HALCON 的运行授权。
